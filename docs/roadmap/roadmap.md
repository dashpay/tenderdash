# Tenderdash Development

Tenderdash development is tracked in the
[project issues](https://github.com/dashpay/tenderdash/issues) and
[pull requests](https://github.com/dashpay/tenderdash/pulls).
[Releases](https://github.com/dashpay/tenderdash/releases) describe published
versions and their changes.

Architecture decisions and RFCs in this documentation explain design context.
A proposal is not a release commitment or a guarantee that a feature is
implemented. Check the source and release notes for the version you deploy.

To propose work, open an issue describing the use case, expected behavior and
relevant operational constraints.
